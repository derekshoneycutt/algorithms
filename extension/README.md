# Derek's Algorithms VS Code Extension (Next Bootstrap)

This folder contains a clean bootstrap for a new VS Code extension iteration.

It intentionally includes only baseline tooling and entrypoints:

- TypeScript with strict settings
- esbuild bundling for extension host code
- ESLint and markdownlint
- Mocha + `@vscode/test-electron` test harness

No views, commands, or feature-specific architecture are wired yet.
